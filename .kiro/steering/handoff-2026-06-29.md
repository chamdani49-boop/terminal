## ARSITEKTUR HARGA LIVE (penting — hasil debugging panjang)
- **Harga live di UI TIDAK berasal dari workflow GitHub Actions / `data.json`.**
  Commit mode `live` pakai `[skip ci]` (sengaja, agar Cloudflare tak redeploy).
- Sumber harga live = **Worker TERPISAH `terminal-live`** (`worker/src/index.js`,
  deploy manual `cd worker && npx wrangler deploy`) yang baca **Sheet LIVE**
  langsung tiap request, endpoint `/live.json` (cache edge 60 dtk).
- Frontend (`public/index.html`) poll `/live.json` tiap 60 dtk (butuh token dari
  `/api/live-token`), lalu **overlay** ke `DATA`: `_overlayLiveInto` menimpa
  **baris terakhir `price_history`** + `stats[code].current` + `DATA.live[code]`.
- UI baca harga dari **baris terakhir `price_history`** (`renderHero` dst).
  Kalau overlay live TIDAK jalan → UI **fallback ke nilai terakhir Sheet HISTORY**
  (bulanan) → tampak **beku**.
- Gating: hanya poll saat **jam bursa WIB 08:50–16:30 Sen–Jum** & tab aktif
  (fetch pertama force tetap jalan).

### Akar masalah "harga beku" sesi ini (SUDAH BERES)
Worker `/live.json` balas **HTTP 500** karena **`LIVE_SHEET_ID`/`LIVE_GID`
TIDAK ter-set** di environment Worker `terminal-live` (satu-satunya pemicu 500
di kode; token salah → 401; sheet error → 502). Owner sudah set ulang secret
via **Cloudflare Dashboard → Workers & Pages → terminal-live → Settings →
Variables and Secrets** (Type: Secret) → **harga live + semua turunannya jalan.**

### Diagnostik cepat (kalau beku lagi)
Buka `https://terminal.economstock.com/dashboard?livedebug=1` saat jam bursa →
baca kotak hitam: `STOP token` (LIVE_TOKEN_SECRET/langganan), `HTTP 4xx/5xx`
(Worker/secret), `count=0` (gid/parse Sheet), `overlay n=0` (GATE price_history),
`LIVE vs price_history.last ✗ beda` (overlay tak menimpa).

## Catatan operasional
- **Selalu pakai github power tools** (push_to_remote/pull_repository/create_pull_request), push ke branch baru. **Saat jam bursa, push langsung ke `main` sering kalah balapan** dengan bot auto-refresh (commit mode live tiap 5 mnt) → lebih andal lewat **PR lalu Merge di GitHub**.
- File data auto-refresh JANGAN diikutkan PR fitur (`public/data.json`, `headlines.json`, `insights.json`, `macro.json`, `ohlc.json`, `valuation/*.json`).
- Worker `terminal-live` **tidak auto-deploy** dari git — harus `wrangler deploy` manual. Pastikan secret-nya: `LIVE_SHEET_ID`, `LIVE_GID`, `LIVE_TOKEN_SECRET` (sama dgn Worker utama), `CONSENSUS_SHEET_ID/GID`, `HISTORY_SHEET_ID/GID`.

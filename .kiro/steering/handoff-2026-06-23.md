## Anti-abuse (`src/lib/abuse.js`) — 3 step, semua aktif
- **Rate limit** per-user di endpoint data .json (default 120/mnt via `RATE_LIMIT_PER_MIN`)
  → 429 + flag. **FAIL-OPEN** (D1 error tidak blokir user). Admin dikecualikan.
- **Deteksi akun dibagi** (`trackDevice`): catat IP/negara per user/hari (tabel
  `account_ips`); flag bila >8 IP atau >3 negara/24j (`ACCOUNT_MAX_IPS_PER_DAY`,
  `ACCOUNT_MAX_COUNTRIES`). Hanya FLAG, tidak auto-block.
- **Notif Telegram** (`sendTelegram`/`reportAbuse`, throttle/jenis): butuh secret
  `TELEGRAM_BOT_TOKEN` & `TELEGRAM_CHAT_ID` (user sudah set & test OK).
- **Auto-suspend OPSIONAL** (`ABUSE_AUTOSUSPEND="true"`, default OFF): suspend bila
  ≥12 flag/24j; idempoten; notif Telegram. Unsuspend via toggle ⛔ di tabel user.
- Suspend = user tak bisa buka dashboard/data (redirect billing); masa aktif TETAP
  jalan (tidak di-pause); reversible.

## VALUASI — ARSITEKTUR TERKINI (MENGGANTIKAN monolith di doc lama)
> ⚠️ Doc `valuasi-context.md` menyebut **`public/valuation.json` (monolith)** —
> itu **SUDAH TIDAK DIPAKAI**. Sekarang **SPLIT + LAZY-LOAD** (PR #257).

**Output build (`scripts/build-valuation.py`) → direktori `public/valuation/`:**
- `index.json` (~70KB): daftar ringan [code, name, sector, applicable, potential_pct,
  last_price] + `assumptions`. Untuk dropdown/search/default.
- `<CODE>.json` (~16KB): data lengkap 1 saham (annual, quarters, valuation models).
- `dividends.json`: dps semua saham (untuk halaman Simulasi `loadValuationDiv`).
- Monolith `valuation.json` **dihapus**. File per-saham basi (kode dihapus/diganti)
  otomatis dibersihkan. Output compact + `_shrink_floats` (buang ekor float).

**Frontend (`public/index.html`, modul `vl*`):** `init()` muat `index.json` →
dropdown/search/default instan; **`ensureStock(code)`** lazy-fetch `<CODE>.json`
saat saham dibuka; render lain (`curStock`) tak berubah. `state.index` (daftar) +
`state.raw.stocks` (diisi lazy). `loadValuationDiv` → `valuation/dividends.json`.

**Gating:** `/valuation/` ada di `PROTECTED_PREFIXES` (src/index.js) & `run_worker_first`
(wrangler.toml). File per-saham di-commit ke repo (hindari gap 404 saat deploy).

### Logika harga & turunan (build-valuation.py)
- **Sumber harga tahunan (urutan):** nilai Excel → `price_history` (data.json, 2016+)
  → **Yahoo year-end** (`history-yearly.json`, <2016). Workflow `refresh-yearly-close.yml`
  (mingguan + dispatch) bangun `public/history-yearly.json` dari Yahoo (script
  `scripts/build-yearly-close.js`).
- **Holiday-fill** (`fill_holiday_prices`): isi harga 'Libur'/kosong + recompute
  `market_cap=price×shares` & rasio (pbv/per/psr). HANYA isi yang None, tak timpa.
  - Kolom **tahunan I–Z**: dari history (tutup tahun).
  - Kolom **kuartal D–G (Q1–Q4)** = bulan 3/6/9/12: dari history bulan itu, **hanya
    bila sel berisi 'Libur'** (kosong = belum lapor → dilewati). Future-proof Q2–Q4.
  - Kolom **H "tahun berjalan"**: dari **harga LIVE** (logika tahun-berjalan-pakai-live
    tetap berlaku; engine `last_price = live || q1.price`).
- **Skip saham data 0/kosong** (`_is_empty_stock`): file Excel yang rumusnya belum
  terhitung (semua sel 0) → saham DILEWATI (tidak muncul "Rp 0"). **Penting untuk
  user:** Excel harus disimpan dengan **nilai sudah terhitung** (bukan rumus cached 0).

### UI tabel fundamental
- Format satuan **Miliar (M) ADAPTIF** (`fmtM`/`fmtMrp`/`_inMiliar`): nilai <1 M
  (mis. emiten lapor USD spt SMDR) tampil desimal, tidak dibulatkan jadi 0/1.
- **% perubahan = YoY** (vs tahun sebelumnya), **bukan vs tahun terlama**. Lonjakan
  absurd (>20x / <0.05x) dilewati (indikasi ganti unit IDR↔USD).
